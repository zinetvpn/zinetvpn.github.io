# نقشه هم‌پوشانی محتوا

دامنه اصلی در ۱۳ سپتامبر ۲۰۲۶ بررسی شد. صفحه خانه یک Landing فروش با پلن، قیمت، پرداخت، معرفی تست و بخش بلند راهنمای انتخاب است و مسیرهای جداگانه خرید بر اساس دستگاه/اپراتور، راهنمای اتصال و وبلاگ دارد. بنابراین هم‌پوشانی تجاری جدی است و جداسازی Intent باید حفظ شود.

| صفحه GitHub    | ریسک  | کنترل                                                                                  |
| -------------- | ----- | -------------------------------------------------------------------------------------- |
| خانه           | کم    | Hub آموزشی، نه صفحه فروش/برند اصلی                                                     |
| خرید           | زیاد  | سایت اصلی فروش/پلن است؛ GitHub فقط چک‌لیست ایمنی و تست، بدون قیمت، مزیت محصول یا سفارش |
| دانلود         | متوسط | فقط معرفی منابع رسمی، بدون میزبانی فایل                                                |
| راهنمای دستگاه | متوسط | مراحل کوتاه Task-based، بدون بازنویسی مقاله سایت اصلی                                  |

Canonical همه صفحات Self است چون متن و هدف مستقل نوشته شده‌اند. با این حال صفحه خرید پیش از انتشار نیازمند تأیید مالک است؛ اگر سایت اصلی زاویه چک‌لیست ایمنی را هم گسترش دهد، باید یکی از دو صفحه بازتمرکز یا ادغام شود.
