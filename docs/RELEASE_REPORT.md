# گزارش Release 1.0 — کاندید محلی

تاریخ: ۱۳ سپتامبر ۲۰۲۶. وضعیت: آماده Preview محلی، منتشرنشده.

شش صفحه MVP، Design system، SEO metadata/schema، Sitemap/robots، CTA attribution، Analytics adapter، CI/Deploy و Validatorها پیاده شده‌اند. `npm run build` هفت مسیر را بدون خطا، هشدار یا Hint ساخت. رندر Chrome در موبایل و دسکتاپ بدون Overflow بود. Lighthouse محلی صفحه خانه در هر چهار دسته Performance، Accessibility، Best Practices و SEO امتیاز ۱۰۰ ثبت کرد. `npm audit` نیز صفر آسیب‌پذیری گزارش داد.

Blocker انتشار: تأیید نام/مالکیت حساب و لینک‌های رسمی، تأیید صفحه تجاری-اطلاعاتی، و دسترسی GitHub Pages. Measurement ID و کد ربات موجود نیستند و برای انتشار پایه ضروری نیستند.
