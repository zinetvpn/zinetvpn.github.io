# قواعد SEO فنی

هر صفحه Indexable باید Title، H1، Description، Self-canonical، OG، Breadcrumb و Article schema یکتا داشته باشد. FAQ schema فقط از پرسش‌های قابل‌مشاهده تولید می‌شود. Sitemap فقط خروجی‌های قابل انتشار را فهرست می‌کند و `404` دارای `noindex` است.

Canonical یک سیگنال است و ایندکس‌شدن تضمین نمی‌شود. پس از انتشار، Sitemap باید در Search Console ثبت و انتخاب Canonical با URL Inspection بررسی شود.
